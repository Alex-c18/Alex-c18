## 🚀 Проекты

### 💰 FinanceTracker — fullstack-приложение с деплоем в облако

Веб-приложение для учёта личных финансов: аналитика, графики, цели накоплений, авторизация и REST API. Прошёл **полный цикл** — от разработки до развёртывания в облаке.

🌐 **Живое демо:** https://financetracker-t214.onrender.com
💻 **Код:** [GitLab](https://gitlab.com/Alex-c18/financetracker)

**Что внутри:**
- **Backend:** ASP.NET Core (.NET 10), MVC + REST API, Entity Framework Core
- **Безопасность:** ASP.NET Identity (куки) + JWT-аутентификация для API, изоляция данных по пользователям
- **База данных:** PostgreSQL (миграции, EF Core)
- **Тесты:** xUnit с In-Memory базой (логика + безопасность)
- **DevOps:** Docker (multi-stage build), деплой на Render, секреты через переменные окружения
